# 똑똑 놀이터 — 문제·낱말 자동 업데이트

이 저장소의 `content.json` 을 고치면, 아이 폰의 **똑똑 놀이터 앱이 다음에 켜질 때 자동으로 받아 갑니다.**
(앱 1.4 이상, 인터넷 연결 필요. 연결이 없으면 마지막으로 받은 문제나 앱에 들어 있는 기본 문제를 씁니다.)

## 고치는 법 (GitHub 웹에서)

1. `content.json` 을 열고 연필(✏️ Edit) 버튼을 누릅니다.
2. 문제를 고치거나 한 줄 추가합니다. **줄 끝 쉼표(,)** 를 잊지 마세요 — 목록의 마지막 줄에는 쉼표가 없습니다.
3. 맨 위 `"version"` 숫자를 **1 올립니다** (예: 3 → 4). 올리지 않으면 앱이 새 것으로 알아보지 못합니다.
4. **Commit changes** 를 누릅니다.
5. 몇 분 뒤 Actions 탭에 ✅ 가 뜨면 형식이 맞는 것입니다. ❌ 면 눌러서 몇 번째 줄이 틀렸는지 확인합니다.
   (❌ 인 채로 두어도 앱은 망가지지 않습니다. 틀린 항목만 무시하고 기본 문제를 씁니다.)

GitHub 이 캐시를 쓰기 때문에 고친 뒤 앱에 반영되기까지 최대 10분쯤 걸릴 수 있습니다.

## 항목 형식

| 항목 | 한 줄 모양 | 규칙 |
|---|---|---|
| `ox` | `["문장", 1, "풀이"]` | `[8살 목록, 11살 목록]`. 1 = 맞는 말(⭕), 0 = 틀린 말(❌). 각 목록 10개 이상, 한 번에 10문제씩 무작위 |
| `ko` | `["🍎", "사과"]` | `[8살 목록, 11살 목록]`. 낱말은 한글 2~6글자. 각 8개 이상 |
| `en` | `["🍎", "apple"]` | 영어 소문자 2~9글자. 30개 이상. **앞 25개는 8살용 쉬운 낱말** |
| `jokes` | `"농담"` | 첫 화면 친구가 하는 말. 60자 이하 |
| `wins` / `loses` | `"한마디"` | 게임을 이겼을 때 / 졌을 때 친구 한마디 |

### 영어 문장 은행 (앱 2.2 이상)

모두 `[8살 목록, 11살 목록]` 두 개입니다. 8살 = 초등 고학년, 11살 = 중1 수준.

| 항목 | 한 줄 모양 | 쓰는 게임 | 규칙 |
|---|---|---|---|
| `sent2` | `["I usually eat breakfast at seven.", "나는 보통 일곱 시에 아침을 먹어요.", ["eats", "in"]]` | 문장 만들기, 받아쓰기, 영어 풍선, 듣기 평가 | 영어 문장은 . ? ! 로 끝, 3낱말 이상. 셋째 칸은 헷갈리게 섞을 틀린 낱말(0~4개) — 넣어도 다른 맞는 문장이 되면 안 됨. 각 8개 이상 |
| `ctx` | `["Please ___ the window.", "close", ["eat", "sing", "jump"], "창문을 닫아 주세요."]` | 알맞은 낱말 넣기 | 빈칸 `___` 하나, 오답 3개(정답과 겹치면 안 됨), 맞는 답은 하나뿐이어야 함. 각 10개 이상 |
| `gram` | `["She ___ to school.", ["go", "goes", "going"], 1, "He·She·It + 동사에 -s"]` | 영어 문법 빈칸 | 셋째 칸은 정답 번호(**0부터** 셈). 넷째 칸은 규칙 설명(틀리면 보여 줌). 각 10개 이상 |
| `lis2` | `["A: Where is my cap? B: It is on your bed.", "모자는 어디에?", ["침대 위", "책상 아래", "가방 안"]]` | 영어 듣기 평가 | 첫째 칸을 소리로 읽어 줌(A: B: 는 읽지 않음). 보기 3개 중 **첫 번째가 정답**(앱이 섞음). 각 7개 이상 |
| `read` | `["글 …", [["질문1", ["정답", "오답", "오답"], "글 속 근거 문장"], ["질문2", …]]]` | 영어 독해 | 글마다 질문 정확히 2개, 보기 3개 중 첫 번째가 정답, 근거 문장은 글에 **그대로** 있어야 함. 각 3개 이상 |

- 한 항목만 틀려도 그 항목만 빠지고 나머지는 쓰입니다. 목록 전체가 최소 개수보다 적어지면 그 목록은 앱 기본값을 씁니다.

- 모든 글자에 `<` `>` `&` 는 쓸 수 없습니다 (앱이 지웁니다).
- 그림은 **예전 폰에서도 보이는 이모지**만 쓰세요. 2019년 이후 새로 나온 이모지(🪙 🧱 🧩 🪞 🪨 등)는 안드로이드 8~10 폰에서 네모로 깨집니다.
- 항목을 통째로 빼면 그 항목은 앱 기본값을 씁니다.

## 새 버전 알림 (app.json, 앱 2.4 이상)

새 APK 를 만들면 `app.json` 의 `code`(앱 versionCode)·`version`·`url`(받는 곳)·`note`(한 줄 설명)를 고칩니다.
아이 폰의 앱이 켜질 때 이 파일을 보고, 깔린 앱보다 `code` 가 크면 첫 화면 📊 부모님 칩에 🆕, 부모님 화면 맨 위에 **⬇ 받아서 설치하기** 버튼이 뜹니다.
- `url` 은 `https://drive.google.com/…` 또는 `https://github.com/kimoonz/…` 만 됩니다(앱이 다른 주소는 열지 않음).
- 설치는 안드로이드가 사람에게 묻습니다. 자동으로 몰래 깔리지 않습니다.
- 검사: `node check_app.js`

## 컴퓨터에서 검사하기

```bash
node check.js
```

## 안전 원칙

앱은 이 파일에서 **글자 데이터만** 받습니다. 프로그램 코드는 받지 않으므로, 파일이 잘못되어도 앱이 망가지거나 엉뚱한 동작을 하지 않습니다.
게임 자체(규칙·화면)를 바꾸려면 앱을 새로 빌드해야 합니다.
